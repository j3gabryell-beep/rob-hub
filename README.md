# ROB HUB

App web instalável (PWA) para buscar códigos e alarmes de robôs industriais, funcionando offline.

- Base atual: Yaskawa Motoman DX100 (790 alarmes), extraída do DX100 Maintenance Manual 155492-1CD, cap. 8.3.
- Idiomas da interface: português e inglês.
- Instalar no iPhone: abrir o link no Safari → Compartilhar → "Adicionar à Tela de Início".

Aviso: o texto técnico vem do manual do fabricante, apenas como referência. Este app não é oficial e não tem vínculo com a Yaskawa.
